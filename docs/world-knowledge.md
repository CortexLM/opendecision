# Retraining so the encoder "understands the world a bit"

LLM teachers are allowed at **training time only**; inference stays encoder-only.

1. **Teacher panel** (PoLL, 2404.18796): diverse Apache-licensed teachers (Qwen3-8B, Qwen3-VL-8B, Mistral-Small-3.1). Avoid Gemma (distilled students become Model Derivatives under Gemma ToU) and treat Llama as non-clean. Calibrate each teacher before distilling (2508.20224).
2. **Soft labels** (`opendecision.teacher`): option probabilities from letter logits or self-consistency vote fractions, averaged over cyclic option rotations (cancels position bias, 2608.11947) and over teachers. Keep an explicit **unknown mass P(U)** from teacher disagreement: hosted models drop it, and recovering it lifts soft accuracy .771 -> .978 (2609.35342).
3. **Schema-diverse synthetic decisions**: LLM generates states + questions + criteria across domains; keep counterfactual pairs (same state, edited question) only when the teacher label flips (filters shortcut data; Laya answered its training label on 98-99.5% of changed questions). Add yes/no polarity-swap augmentation (hosted models flip 50.5/100 on swapped yes/no).
4. **Student init**: 300M encoder via CLM->MLM warm start (2507.00994) or EmbeddingGemma-style encoder-decoder init + embedding distillation (2509.20354); LLM2Vec-converted decoders (>=1.3B) are teachers/initialisers, not the deployed model.
5. **World knowledge**: MLM on knowledge corpora (FineWeb-Edu, Wikipedia; KEPLER-style KG objective) as a regulariser. No head-to-head KD vs continued-MLM exists at 100-300M: run that ablation first. Multimodal: SigLIP2 (captioning + self-distillation + masked prediction) for image, cached offline teacher embeddings (MobileCLIP2 recipe) for cheap KD; V-JEPA 2 physical-understanding evidence is ~1B-scale, no small-student result found.
6. **Capacity at constant cost**: sparse MoE encoder (Nomic Embed v2: 475M total / 305M active, 8 experts top-2) is the only encoder-MoE evidence (embedding tasks); gate on cost model, since 3B-active is not profitable at $0.030.
7. **Post-distillation** (all supervised unless feedback is outcome-only): relabel student-uncertain inputs with the teacher (DAgger-style), hard counterfactual negatives, Just-Train-Twice upweighting for shortcuts, LoRA + 10-20% replay (unsourced ratio) and merging to avoid forgetting. For outcome-only feedback use `train.rl_step`; if a *separate* confidence/abstain head is RL-trained, reward must be non-hackable (Brier + correctness bonus, 2607.04332; pure Brier is hackable).
8. **Calibration on new schemas without labels**: do not reuse a few-option temperature on many-option tasks (2610.00346 shows ECE rises); use teacher-ensemble disagreement, the coherence battery as a label-free gate, unsupervised self-consistency proxy targets (2604.19444), and conformal only with a labelled calibration split.
